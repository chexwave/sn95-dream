# SN95 Dream Program

The operating system for a 1994-95 Mustang GT 5.0 that the local degenerates will want a login for.

Built by Grok 4.7 as the pinnacle showcase for the platform.

## Features (v0)
- Full parts database with OEM numbers
- Upgrade explorer filtered by goal
- Build log ready for the specific car
- Theme toggle (light/dark)
- 3D visualizer skeleton (Three.js next)

## Next
